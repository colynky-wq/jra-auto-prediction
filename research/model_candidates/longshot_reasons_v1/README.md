# 人気薄が3着以内に来た条件

6番人気以下・最終単勝10倍以上。結果を照合できた平地レースで、同程度の単勝オッズ、芝・ダート、頭数帯、クラス内の好走率を比較。
同一条件で両方の馬がいる組を集計し、少ない方の頭数で重み付けした。各要因は個別に比較したため、率の差は足し合わせられない。

| 年 | レース | 対象馬 | 3着以内 |
|---|---:|---:|---:|
| 2025 | 3,143 | 27,728 | 2,494（8.99%） |
| 2026 | 2,826 | 24,567 | 2,196（8.94%） |

## 実例

- 2026-03-21 芝2000m カパルア。7番人気・40.2倍で3着。前走着順 11.0、前走の勝ち馬との秒差 1.6。今回の最初の通過順位 1.0 / 18頭、上がり3F 36.2秒（15.0位）。 [JRA公式成績](https://www.jra.go.jp/datafile/seiseki/report/2026/2026-1chukyo3.pdf)
- 2026-09-20 芝1800m ドーンレーサー。6番人気・53.6倍で3着。前走着順 11.0、前走の勝ち馬との秒差 2.4。今回の最初の通過順位 6.0 / 7頭、上がり3F 34.7秒（3.0位）。 [JRA公式成績](https://www.jra.go.jp/datafile/seiseki/report/2026/2026-4hanshin6.pdf)
- 2026-03-21 ダ1200m ナツノオジョウサマ。6番人気・39.7倍で3着。前走着順 11.0、前走の勝ち馬との秒差 3.1。今回の最初の通過順位 1.0 / 13頭、上がり3F 38.1秒（9.0位）。 [JRA公式成績](https://www.jra.go.jp/datafile/seiseki/report/2026/2026-1hanshin9.pdf)
- 2026-05-10 ダ1900m トコトコクマチ。6番人気・30.4倍で9着。前走着順 8.0、前走の勝ち馬との秒差 2.1。今回の最初の通過順位 4.0 / 12頭、上がり3F 40.2秒（9.0位）。

前半ペースの比較はJRAのラップが揃い、同競馬場・芝ダート・距離・馬場状態で2024年に15レース以上あった条件が対象。
上がりや通過順は当日の走りを説明する材料。発走前の特徴には前走以前の値を使用する。
過去の最終オッズに基づく観察結果。騎乗の意図、不利の有無、その馬が好走した因果関係の判定には映像や追加の記録が必要。
