# 初角の参考隊列 v1

過去の初角位置を頭数の違いに合わせて0（先頭）～1（最後方）へ変換し、最大6走の平均で出走馬を並べる。発走前の履歴だけを使い、当日と未来の結果は除く。同名の別世代は馬キーで分ける。新潟の芝1000m直線の通過順位は初角として使わない。

参考順は、過去3走以上の初角履歴がある馬が出走馬の80%以上、かつ3頭以上の場合に限る。この条件と6走の窓は2025年の結果による調整をしていない。2024年で前走だけの方法より平均位置の誤差が小さいことを確認して採用し、2025年を別に評価する。2026年は方法選び・評価に使わない。

2025年は1,877対象レースで、実際の初角先頭馬が参考順の先頭3頭に60.79%含まれた。同じ履歴のある馬から無作為に3頭を選ぶ場合は22.88%、前走だけの方法は58.92%。1頭目だけで初角先頭を当てた割合は31.01%。これらは初角の先頭に関する検証で、1着馬の的中率ではない。2頭の前後関係が一致した割合72.03%も、全馬の隊列を当てた割合ではない。

順位が近い馬や平均が同じ馬の並びは不確か。同じ値の表示順は馬番順であり、順位差に根拠があるとは扱わない。未収録・履歴不足の馬を最後方や低確率とみなさない。新馬が多いレースは隊列表示を保留する。

逃げ傾向の頭数は、収録済みの履歴で逃げが50%以上の馬の数。前方傾向の頭数は、逃げと先行を合わせて50%以上の馬の数。どちらも今回その戦法を取る確率や、全出走馬についての断定ではない。

保存データには馬ごとの走破タイムと上がり3Fはあるが、先頭基準の前半レースラップはない。このためS/M/Hなどのペース分類や、逃げ候補数からのペース予想は未検証であり表示しない。公式の前半ラップを独立した補助データとして蓄積し、コース・距離ごとに比較可能な基準を作る段階が必要。

通常の37特徴量勝率モデル、正式な大穴v1、購入金額配分には接続しない。AppResearchData.jsonへ任意項目として追加し、古いアプリや古い研究JSONでも既存表示を保つ。

再現:

```bash
python -m unittest discover -s production -p 'test_formation_reference.py'
python production/research_formation.py
python production/build_app_research_data.py --evaluate
```

詳しい検証条件と結果はreports/FormationValidation.jsonに保存する。
