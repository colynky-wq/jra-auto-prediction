# KeibaAI 複合馬券ポートフォリオ研究 v1

Version: `portfolio-shadow-v1-20261019`

## 目的

「荒れ度 × 勝負度 × 券種」を使い、1レースにつき **単独券種または複合馬券プランを1つだけ**研究表示する。

これは購入指示ではなく、将来の馬券選択ロジックを前向き検証するための shadow 研究である。

- formalRecommendationsEnabled = false
- autoBetEnabled = false
- stakeSizingEnabled = false
- 1点100円固定
- V1予測モデル、SignalDataの正式シグナル、既存の券種研究ルールは変更しない

## データの扱い

`2026-10-24` を前向き評価開始日とする。

- 2026-10-23以前: `development_backfill`
  - 既に保存された発走前データを使い、研究ロジックの動作確認・説明用に再構成する
  - 成績証明には使わない
- 2026-10-24以降: `prospective`
  - この文書とコードで固定したルールを変更せず評価する
  - 結果を見て閾値を変更した場合は新しいバージョンを作り、旧v1と混ぜない

## レース分類と研究プラン

### 荒れ度 1〜2: 単勝1点

勝負度が S/A/B で、単勝候補が以下を満たすときだけ対象。

- AI勝率 18%以上
- 発走前オッズによる期待倍率 1.05以上

条件不足なら見送り。

### 荒れ度 3: 単勝 + ワイド

勝負度が S/A/B で、主軸単勝が以下を満たす場合に研究する。

- AI勝率 15%以上
- 単勝期待倍率 1.03以上

同じ主軸馬を含むワイドから、以下を満たす組み合わせを最大2点。

- AI同時3着内確率 7%以上
- 保守的期待倍率 1.05以上

ワイド候補がなければ見送り。

### 荒れ度 4〜5: ワイド中心 / ワイド + 3連複

混戦では勝負度 A/S のみ対象。

ワイドは最大2点。

- AI同時3着内確率 5%以上
- 保守的期待倍率 1.10以上

3連複は次の条件を満たす場合のみ1点追加。

- AI的中確率 4%以上
- 期待倍率 1.10以上

条件不足ならワイドだけ、ワイド条件も満たさなければ見送り。

## 評価指標

回収率だけで採否を決めない。最低限、以下を保存する。

- 対象レース数
- 選択レース数
- 見送りレース数・参加率・見送り率
- 何か1点以上当たったレース数・的中レース率
- レース単位で利益が出た回数・利益レース率
- トリガミ回数・トリガミ率
- 総投資額
- 総払戻額
- 損益
- 回収指数
- プラン別成績
- 荒れ度別成績
- 勝負度別成績
- 見送り理由の内訳

## 100R短期レビュー

`production/portfolio_review_100.py` が `PortfolioReview100.json` を自動生成する。

- 対象は **2026-10-24以降の最初の100レース** を時系列で固定する
- 101R目以降が追加されても、最初の100Rレビューの母集団は変更しない
- 100Rに達しても選択レースの結果が未確定なら `target_reached_results_pending`
- 100Rに達し、選択レースがすべて確定したら `ready_for_short_term_review`
- development/backfill は100Rレビューに混ぜない
- 異なる ruleVersion が混ざった場合は失敗させる

短期100Rでは合否を決めない。動作異常・極端な失敗・参加率・見送り率・的中・利益・トリガミ・プラン構成を点検する。

100Rの結果を見てv1の閾値を変更しない。変更案は必ず `portfolio-shadow-v2-*` として分離する。

## 変更ルール

2026-10-24以降の結果を見てv1の閾値を変更しない。
改善案は `portfolio-shadow-v2-*` として別系統でshadow運用する。
